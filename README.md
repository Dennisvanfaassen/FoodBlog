# Aan Tafel & In het Glas

Nederlandse persoonlijke foodblog met één artikel over drie wijnstijlen en vijftien tapasideeën.

## Softwarekeuze
Statische HTML, CSS en een klein JavaScript-bestand voor afdrukken. Geen installatie, database, trackers, externe fonts of betaalde diensten. De volledige inhoud is leesbaar zonder JavaScript. Deze keuze houdt de blog snel, eenvoudig en geschikt voor GitHub Pages.

## Publicatie
GitHub Settings → Pages → Deploy from a branch → main → /(root).
Verwachte URL: https://dennisvanfaassen.github.io/FoodBlog/
Artikel: https://dennisvanfaassen.github.io/FoodBlog/wijn-bij-tapas/

Bij een ander domein: pas canonical, Open Graph, BlogPosting, sitemap en robots aan.

## Inhoud aanpassen
Homepage: index.html. Artikel: wijn-bij-tapas/index.html. Stijlen: assets/style.css.
AI-gegenereerde beelden in WebP op 480 en 960 pixels, met alt-teksten, vaste afmetingen en lazy loading behalve de hero. Beelden zijn illustratief; garnering kan afwijken. Geen verzonnen reviews of Recipe-schema: dit artikel bevat bereidingssuggesties, geen geteste recepten met afgewogen hoeveelheden.

## SEO
Unieke titels en beschrijvingen, canonical URL, semantische koppen, interne navigatie, Open Graph, BlogPosting JSON-LD en sitemap. Een robots.txt in een projectsubmap geldt niet als robotsbeleid voor het hele github.io-domein. Dien de sitemap zo nodig rechtstreeks in Search Console in. Indexering en zoekposities zijn niet gegarandeerd.
